# Красвордс — стратегия роста

Last update: 2026-07-06. Живой документ: дополнять при каждом стратегическом решении.

## Позиционирование

**«Кроссворды, которые не выглядят как газета»** — тематические (фандомы, поп-культура, игры), каждый с уникальным визуалом/темой, с таймером, топом и ачивками. Конкуренты в рунете — либо унылые генераторы сканвордов, либо мобильные приложения с агрессивной рекламой. Ниша «красивый веб + фандомы + соревнование» свободна.

Целевая аудитория (по порядку приоритета):
1. **Фандомная молодёжь 16–30** (Рик и Морти, ГП, аниме, игры) — приходят за темой, остаются за стриком.
2. **Казуальные решатели 25–45** — «5 минут в обед», мобильный трафик.
3. **Учителя/студенты** — кроссворды по темам как микро-обучение (дальний прицел).

## Ключевая механика роста: контент × привычка × шеринг

### 1. Контент — главный рычаг (сейчас узкое место)
- **Ритм публикаций**: минимум 3–5 новых кроссвордов в неделю. Пустая главная = смерть retention. Использовать `/api/admin/import-crossword` + генерацию слов через LLM с ручной проверкой (пайплайн: тема → 15 слов+определения → раскладка в редакторе → публикация за ~20 мин).
- **Кроссворд дня** — уже есть hero-карточка; довести до автоматики (queue публикаций по расписанию). Ежедневный контент = ежедневный повод зайти.
- **Хайп-темы под релизы**: новый сезон сериала / игра / мем недели → кроссворд в день выхода → пост в фандомных пабликах. Это бесплатный таргетинг: аудитория уже собрана в сообществах.

### 2. Привычка (retention)
- **Стрик как в Duolingo** — серия уже считается в профиле; вывести её на главную (флейм-бейдж в Nav), пуш «серия сгорит через 3 часа» после подключения PWA-уведомлений.
- **Ежедневный челлендж** (из бэклога — поднять приоритет): один кроссворд, у всех одинаковый, отдельный топ дня. Создаёт эффект Wordle — «а ты сегодняшний решил?».
- **Подсказки** (из бэклога, высокий приоритет) — снижают отвал новичков на первом кроссворде. Первый решённый кроссворд = ключевой aha-момент, всё до него должно быть без трения (гостевая игра уже есть — ✅).
- **Автосохранение прогресса** (бэклог) — не терять начатое = возвращаемость.

### 3. Шеринг (виральность)
- **Результат-картинка** (бэклог, поднять приоритет): PNG «Решил „Рик и Морти" за 3:41, топ-5» с брендом и ссылкой — в Telegram/WhatsApp. OG-картинки уже есть — половина работы сделана.
- **Wordle-паттерн для челленджа дня**: шеринг эмодзи-сетки без спойлеров + «сможешь быстрее?». Это главный вирусный контур.
- **Вызов друга**: ссылка «побей моё время» — открывает кроссворд с призраком чужого результата.

## Каналы привлечения (по стоимости, от бесплатных)

1. **SEO** — фундамент уже есть (sitemap, OG, метаданные). Действия: подключить боевой домен красвордс.com к Vercel (сейчас sitemap указывает на него, а прод на vercel.app — **исправить в первую очередь**), Яндекс.Вебмастер + Search Console, страницы-хабы по категориям («кроссворды по Гарри Поттеру онлайн»). Низкочастотники по фандомам почти без конкуренции.
2. **Telegram** — основной канал для RU-аудитории. Канал «кроссворд дня» + бот с уведомлениями. Посев: взаимопиар с фандомными каналами 5–50к, там дешёвые размещения.
3. **Фандомные сообщества** — VK-паблики, Пикабу, Reddit r/rickandmorty (для EN-версии позже). Не реклама, а «сделал кроссворд по вашей теме, зацените» — органика.
4. **Короткие видео** (TikTok/Shorts/Reels/VK Клипы): скринкаст решения со звуком, «угадай слово за 5 секунд». Дёшево тестировать, один залетевший ролик = тысячи переходов.
5. **Платно — только после product-market fit** (retention D7 > 15%): Telegram Ads / VK таргет на фандомные интересы.

## Монетизация (не раньше 1000 DAU)

1. **Реклама** (РСЯ/AdSense) — межигровой экран, не в игре. Быстро, но дёшево и портит продукт. Только как временный мост.
2. **Премиум ~149₽/мес**: безлимит подсказок, эксклюзивные темы/декорации, статистика, бейдж в топе, без рекламы. Основная модель.
3. **Спонсорские кроссворды** — брендированный кроссворд под релиз фильма/игры (продаётся напрямую маркетингу). Уникальное предложение, высокий чек.
4. **B2B/образование** — конструктор для учителей (свой кроссворд по ссылке для класса). Отдельный продукт на той же базе, монетизация подпиской школы.

## Метрики (смотреть еженедельно)

| Метрика | Цель 3 мес |
|---|---|
| DAU | 300 |
| D1 retention | > 25% |
| D7 retention | > 12% |
| Completion rate первого кроссворда | > 60% |
| Доля сессий с шерингом | > 5% |
| Новых кроссвордов/нед | ≥ 4 |

Подключить аналитику: Vercel Analytics + Яндекс.Метрика (вебвизор покажет, где бросают решение).

## Роадмап

**30 дней — фундамент привычки**
1. Домен красвордс.com на прод + Вебмастер/Search Console
2. Подсказки в игре (2–3 за игру)
3. Автосохранение прогресса
4. Контент-пайплайн: 15+ опубликованных кроссвордов, ритм 4/нед
5. Яндекс.Метрика

**60 дней — виральный контур**
6. Ежедневный челлендж + отдельный топ дня
7. Шеринг результата картинкой + эмодзи-сетка
8. Telegram-канал + автопост нового кроссворда
9. Стрик на главной + PWA-уведомления

**90 дней — масштабирование**
10. Посевы в фандомных сообществах под хайп-релизы
11. Короткие видео (10 роликов, замер CTR)
12. Оценки кроссвордов ⭐ → сортировка по рейтингу
13. Решение по монетизации на основе retention-данных

## Риски

- **Контент-голод** — без ритма публикаций всё остальное бессмысленно. Митигация: LLM-пайплайн + bulk import.
- **Один человек** — не распыляться: сначала retention (30 дней), потом каналы. Не делать EN-версию, B2B и приложение, пока RU-веб не растёт сам.
- **Авторские права на фандомы** — названия/темы ок, официальные арты — нет. Свои стилизации (уже так и сделано с темами).
